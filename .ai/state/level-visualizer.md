## Проверенные инварианты level 19 (для тестов)

- 16 чанков (1.234 МБ) + index (13 КБ) + skeleton (61 КБ) + report (15 КБ) = 19 файлов, ~1.32 МБ без source.
- Уникальные: 28 домов, 122 дороги, 2626 пропов; instances: 35/169/2626; 54 дубля.
- Source: 84 сегмента / 80 узлов; отчёт: 120/98; собранных дорог 122 = 58 exact + 62 split (18 вложенных) + 2 pad;
  все 84 source-сегмента представлены, 0 unknown / 0 missing.
- Дома `b_d0_*` (28) — generated; все пропы `pillar_*` / `concrete_pillar` / `bridge_pillar` — derived,
  47 родительских дорог; район `d0/forest` — authored rect на всю плиту.
- В отчёте 18 repairs (`resolve_road_crossing`, node + segments), 5 warn-диагностик, 40 diagnostics.
- `generation-report.districts[]` без геометрии; `d0` — `parcels=441`, `cells=0`.

## Исправленные факты после перепроверки

- У 16/17 **по 16 авто-районов** `district_i_j` (не 12), `cells:1`, только в отчёте, без геометрии.
- 16/17 source почти пуст (4 КБ): 0 дорог/домов/пропов; всё создаёт citygen. `source`-режим для них — metadata-only.
- `owner` — маркер владельца, не копии: число `owner: true` равно unique (L19 2776, L16 1137, L17 960, L18 179).
  `index.cells[].objects` — instances (L19 35/169/2626), не unique.
- `roads[].pillars` — те же объекты, что top-level `props` (L19 2626, L18 152); вложенных вхождений 4656/330.
  Рисовать только top-level, не двоить.
- `prop_<n>` в 16/17 имеет `source:"authored"`, но создан stage 5 → `generated`.
- Отчёт: L16 `buildings 402 − 10 drops = 392`, `props 360 + 202 pillars = 562`;
  L17 `403 − 7 = 396`, `360 − 2 + 24 = 382`; L19 `props 0`, но 2626 derived pillars.
- В 07/15 к source-дорогам добавляются портальные площадки `tunnel_<tunnelId>_pN` (по 2) — derived с parent-тоннелем,
  не unknown: L07 6 exact + 2 pad + 2 tunnel = 10; L15 19 + 2 + 2 = 23; L10 — 16 + 1 pad = 17.
- Source `cityforge.chunks[]` (`chunks/i_j/chunk.json`) — манифест, не пути к `.l14b`; пути берём из `map.cells`.
- `metadata.notes` может отставать (L19 пишет «без домов», а домов 28); истина — данные/отчёт.
- Source объявляет `up: "Z"`, но данные Y-up — визуализатор нормализует Y-up и показывает предупреждение.

## Решения

- Инструмент: `tools/level-visualizer.html` + `tools/visualizer/*.js`, Three.js 0.160 importmap, без сборщика.
- Исходник грузится всегда; режимы `source` / `compiled` (default, если есть `index.js`) / `compare`.
- Цвет = редактируемость; штрих = характер; сплиты авторской дороги остаются `authored` с `parentId`.
- Районы: source rect/polygon (`d0`); авто-районы — баннер + опциональный `inferred` hull/AABB из домов.
- Метки: собственный DOM-пул, экранный declutter, бюджет 60, safe-area панелей, гистерезис.
- Рельеф — опциональный слой из `map.relief.hills` (контекст, не коллизия).
- Авто-районы как настоящие полигоны — только TASK-009 (изменение пайплайна, не входит в основной объём).
