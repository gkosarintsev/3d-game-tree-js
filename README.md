# 3D Шутер

Небольшая игра на Three.js (ES-модули, без сборщика): процедурный город и горный
перевал, сбор монет, враги и две играбельные роли — **Человек** (автомат) и
**Чужой** (лазает по стенам и потолку, бьёт рукой, прыгает вперёд). Игра состоит
из глав-уровней, идущих одна за другой, как в Half-Life: интертитр главы → цель
главы → следующая глава (см. `src/levels/`). Первые три главы — переходы «из
точки A в точку B» (глава 1 — рельеф: горы, пещеры, пропасть с мостом; главы 2–3 —
пока заготовки с одной монетой), главы 4–7 — улицы со сбором монет.

## Запуск игры

Проект использует ES-модули и `importmap`, поэтому открывать `3d-game.html` напрямую
через `file://` нельзя — нужен локальный HTTP-сервер. Из корня проекта выполните:

```bash
python -m http.server 8124
```

и откройте в браузере:

```
http://localhost:8124/3d-game.html
```

Подойдёт любой статический сервер (`npx serve`, `php -S localhost:8124` и т.п.).
Единственная внешняя зависимость — Three.js 0.160, подгружается с CDN по `importmap`
(нужен доступ в интернет).

### Отладочное меню

Добавьте к адресу `?debug=1`:

```
http://localhost:8124/3d-game.html?debug=1
```

Справа появится панель (`src/debug.js`): выбор и загрузка любой главы,
перезагрузка текущей главы и live-правка параметров CONFIG (скорость, прыжок,
оружие, враги, свет, FOV). Поля со значком ⟳ применяются после перезагрузки главы.

## Управление

| Клавиши | Человек | Чужой |
| --- | --- | --- |
| `W` `A` `S` `D` | движение | движение |
| `Shift` | бег | бег |
| `Space` | прыжок | прыжок вперёд (по взгляду) |
| `ЛКМ` | огонь | удар рукой |
| `Esc` | пауза | пауза |

## Запуск тестов

Тесты — это модули, которые проверяют физику и логику лазания/врагов. Они импортируют
`three` по `importmap`, поэтому запускаются **в браузере** на странице игры, а не в Node.

1. Запустите сервер и откройте `http://localhost:8124/3d-game.html`.
2. Откройте консоль разработчика (`F12`) и выполните:

```js
// механика лазания Чужого (18 тестов)
const climb = await import('/tests/alien-climb.test.js');
climb.runAlienClimbTests();

// враги-Чужие (5 тестов)
const enemy = await import('/tests/alien-enemy.test.js');
enemy.runAlienEnemyTests();

// карта-рельеф первой главы (18 тестов)
const terrain = await import('/tests/terrain-traverse.test.js');
await terrain.runTerrainTests();
```

Каждый модуль печатает отчёт `PASS/FAIL` и итог `N/M` в консоль, а также возвращает
объект `{ passed, total, results }`.

> Если после правок браузер отдаёт старую версию модулей из кэша, отключите кэш
> (DevTools → Network → «Disable cache») и перезагрузите страницу, либо запустите
> сервер на новом порту.

## Структура

```
3d-game.html        разметка, стили и importmap
AGENTS.md           архитектурные ограничения проекта (обязательны к чтению)
src/
  main.js           точка входа (и отладочный window.game)
  debug.js          отладочное меню (?debug=1): главы и live-параметры
  game.js           движок: последовательность глав, игровой цикл и состояния
  config.js         настройки по умолчанию (свет, физика, враги, декор, рельеф)
  levels/
    index.js        реестр глав: порядок массива = порядок прохождения
    level-01.js     глава 1 — Перевал (рельеф: горы, пещеры, пропасть; цель — точка B)
    level-02.js     глава 2 — Пустошь (заготовка перехода, 1 монета)
    level-03.js     глава 3 — Предгорье (заготовка перехода, 1 монета)
    level-04.js     глава 4 — Первый дом (один дом, вводная)
    level-05.js     глава 5 — Окраина (пять домов, день)
    level-06.js     глава 6 — Квартал на закате
    level-07.js     глава 7 — Высотки (пасмурно)
  map.js            карта-улица (TownMap): опорные поверхности, коллизии, пути, миникарта
  terrain-map.js    карта-рельеф (TerrainMap): колонки высот, пещеры, пропасти, мосты
  solids.js         общий механизм AABB-солидов (рейкаст, сфера, маршевый луч)
  exit.js           цель-«выход» глав-переходов (маяк точки B)
  building.js       процедурная генерация зданий
  decor.js          декор: пальмы, уличные фонари, оборудование крыш
  player.js         игрок-человек (движение, гравитация, коллизии)
  alien.js          физика Чужого (лазание, прилипание, прыжок вперёд, удар рукой)
  enemies.js        враги: люди и Чужие
  weapon.js         стрельба
  coins.js          монеты
  hud.js            интерфейс: здоровье, миникарта, оверлеи
  effects.js        трассеры выстрелов
  audio.js          звук (Web Audio API)
tests/
  alien-climb.test.js       механика лазания Чужого
  alien-enemy.test.js       враги-Чужие
  terrain-traverse.test.js  проходовость карты-рельефа
```

Новая глава — новый файл-определение в `src/levels/` + строка в `index.js`;
движок и карту править не нужно (уровень = данные, см. AGENTS.md).
