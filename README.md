# 3D Шутер

Небольшая игра на Three.js (ES-модули, без сборщика): процедурный город, горный
перевал и макет ночного города из готового GLB-ассета, сбор монет, враги и две
играбельные роли — **Человек** (автомат) и **Чужой** (лазает по стенам и потолку,
бьёт рукой, прыгает вперёд). Игра состоит из глав-уровней, идущих одна за другой,
как в Half-Life: интертитр главы → цель главы → следующая глава (см. `src/levels/`).

| Глава | Тип карты | Цель |
| --- | --- | --- |
| 1. Перевал | `terrain` — рельеф: горы, пещеры, пропасть с мостом | дойти до точки B |
| 2. Ночной город | `city` — сетка кварталов с домами и фонарями | дойти до точки B |
| 3. Ночной район | `model` — район 700 м из GLB-макета города | дойти до точки B |
| 4. Весь город | `stream` — тот же макет целиком (~4,3 × 3,0 км), твёрдость приходит активным окном 780 м и переставляется по ходу пути | дойти до точки B (~1,1 км пешком) |
| 5. Первый дом | `town` — одна улица, вводная | собрать монеты |
| 6. Окраина | `town` | собрать монеты |
| 7. Квартал на закате | `town` | собрать монеты |
| 8. Высотки | `town` | собрать монеты |
| 9. Сводная из JSON | `json` — уровень, собранный из брифа: дома с комнатами и этажами, три вида маршей, улицы двух ярусов, насыпь и эстакада | дойти до точки B |
| 10. Неоновый мегаполис | `json` — тот же механизм плюс генератор кварталов: 600 × 600 м, река с бродами и мостами, ходовые кровли, переходы между башнями | дойти до точки B |
| 11. Развязка | `json2` — поворотный город: дома и улицы под углом к северу, настил дугой с подъёмом и поперечным креном, развязка с мостом, переход, лестница-шахта | дойти до точки B |
| 12. Рельефный мегаполис | `json2` + `relief` — 600 × 600 м с плавным рельефом: набережные и порт на нуле, деловой центр на террасе +14,8 м, три моста, эстакада и развязка банкованными дугами, улицы и перекрёстки по профилю поля, косые районы (`yaw`, `polygon`), иглы с переходом между кровлями | дойти до точки B (~730 м пешком, с яруса на ярус) |

Главы 1–4 и 9–12 — переходы «из A в B» (цель `exit`), главы 5–8 — улицы со сбором
монет (цель `coins`). Смерть перезапускает текущую главу.

## Запуск игры

Проект использует ES-модули и `importmap`, поэтому открывать `3d-game.html` напрямую
через `file://` нельзя — нужен локальный HTTP-сервер. Из корня проекта выполните:

```bash
python -m http.server 8124
```

и откройте в браузере:

```
http://localhost:8124/3d-game.html
```

Подойдёт любой статический сервер (`npx serve`, `php -S localhost:8124` и т.п.).
Единственная внешняя зависимость — Three.js 0.160, подгружается с CDN по `importmap`
(нужен доступ в интернет).

### Отладочное меню

Добавьте к адресу `?debug=1`:

```
http://localhost:8124/3d-game.html?debug=1
```

Справа появится панель (`src/debug.js`): выбор и загрузка любой главы,
перезагрузка текущей главы и live-правка параметров CONFIG (скорость, прыжок,
оружие, враги, свет, FOV). Поля со значком ⟳ применяются после перезагрузки главы.

Кнопка «Показать id объектов» подписывает прямо в мире id объектов уровня — дома,
комнаты по этажам, марши, двери, дороги с их плитами, откосами и насыпями,
инстансы и огни. Надпись висит над своей геометрией и видна сквозь стены, так что
её можно прочитать и потом найти в `src/levels/level-09.json` (или `level-11.json`
для главы v2). Точки отдаёт карта
(необязательный член контракта `debugIds()`), поэтому метки есть только у глав из
брифа.

## Запуск тестов

Тесты — это модули, которые проверяют физику и логику лазания/врагов. Они импортируют
`three` по `importmap`, поэтому запускаются **в браузере** на странице игры, а не в Node.

1. Запустите сервер и откройте `http://localhost:8124/3d-game.html`.
2. Откройте консоль разработчика (`F12`) и выполните:

```js
// механика лазания Чужого (21 тест)
const climb = await import('/tests/alien-climb.test.js');
climb.runAlienClimbTests();

// враги-Чужие (5 тестов)
const enemy = await import('/tests/alien-enemy.test.js');
enemy.runAlienEnemyTests();

// карта-рельеф первой главы: проходовость гор, пещер и мостов (18 тестов)
const terrain = await import('/tests/terrain-traverse.test.js');
await terrain.runTerrainTests();

// глава 2 — город кварталов: контракт карты, навигация, дома (15 тестов)
const city = await import('/tests/city-level.test.js');
await city.runCityTests();

// глава 3 — район из GLB-макета: растерка колонок, маршрут, лазанье (24 теста)
const model = await import('/tests/model-level.test.js');
await model.runModelTests();

// ночной свет: пул огней, туман, затемнение диффузии макета (7 тестов)
const lights = await import('/tests/night-lights.test.js');
lights.runNightLightsTests();

// глава 4 — стриминг макета: окно, корзинки тайлов, стыки, перестановка (11 тестов)
const stream = await import('/tests/stream-map.test.js');
await stream.runStreamTests();

// глава 9 — уровень из JSON: солиды и опоры, проём перекрытия, посадки маршей,
// опора под каждым ребром графа, гладкий наклонный пролёт эстакады, сфера тела
// на пролётах и откосах, швы полов и кровли, метки id, маршрут A→B,
// русло с бродами и река без брода, ходовые кровли с парапетом, лестница-шахта
// и переход в дверь на отметке пола, квартал генератора — все этажи и кровли
// достижимы, дверь выходит на решётку улицы, светящиеся окна фасадов, мусор
// кровель-тротуаров и неон вывесок — картинка, а не твёрдость (50 тестов)
const json = await import('/tests/json-level.test.js');
await json.runJsonTests();

// общий механизм твёрдых объёмов: ориентированная коробка (v2 генератора
// города) — луч, нормаль, выталкивание сферы, опора плиты под 30° против
// независимой арифметики; при yaw = 0 результаты равны обычному AABB побитово
// (10 тестов)
const obb = await import('/tests/rotated-solid.test.js');
obb.runRotatedSolidTests();

// косой дом v2 — дом под 30°: картинки, коллизия, опоры и навигация в одном
// угле; пустой угол габарита свободен, луч бьёт в косой фасад на аналитическом
// расстоянии, марши и кровля достижимы, окна/неон/мусор снаружи стен, метки id
// в мире, миникарта печатает четырёхугольник, маршрут A→B, главы 9–10 не
// двинулись (12 тестов)
const slant = await import('/tests/rotated-house.test.js');
await slant.runRotatedHouseTests();

// косые настилы дорог v2 — пластина под 20–30°: опора, луч, сфера и граф живут в
// осях полотна, подъём с земли на верхний настил проходим ногами, опоры и фонари
// повёрнуты вместе с полотном, миникарта печатает четырёхугольник, метки id
// различают угол, главы 9–10 остались на v1 (12 тестов)
const road = await import('/tests/rotated-road.test.js');
await road.runRotatedRoadTests();

// дуги полотна v2 — развязка поднимается и поворачивает одной дугой: верх
// считается по углу и радиусу (не по габариту), опора и сфера живут в секторе,
// с земли под эстакадой дуга не «держится» сквозь пролёт, пустой угол габарита
// и отверстие кольца не трогаются, тело самоходом проходит подъём и спуск,
// луч бьёт в ту же нарезку, что нарисована (≤ 0,05 м), перила бракуют край, но
// не осевую, граф поднимается на полотно по осевой дуги и доводит до точки B
// (узлы на плоскости дуги, карманов нет), миникарта печатает кольцевой сектор,
// крен сходит к нулю на обоих срезах, а гребень кромки полотна заключён между
// отметками торцов — к стыку с прямым настилом приходит снизу, главы 9–10 не
// двинулись (17 тестов)
const sweep = await import('/tests/rotated-sweep.test.js');
await sweep.runRotatedSweepTests();

// глава 11 v2 целиком — маленький район со всеми элементами поворотного города:
// косые дома и настилы под yaw, развязка дугой на мост и съезд на землю, переход
// между домами, русла с бродом, ходовые кровли с лестницей-шахтой, маршрут A→B
// по дуге, метки id и миникарта-сектор, окна/мусор/неон — картинка (17 тестов)
const json2 = await import('/tests/json2-level.test.js');
await json2.runJson2Tests();

// плавный рельеф (`relief`) в движке: нога, пуля, сфера и картинка грунта идут по
// одному полю (марш луча целым числом проб, зазор сферы r/cos, отсчёт опоры с
// отметки местности), решётка навигации мельчит ребро на склоне и доводит между
// ярусами, главы 9–11 не двинулись (12 тестов)
const rt = await import('/tests/relief-terrain.test.js');
await rt.runReliefTerrainTests();

// улицы главы по рельефу: независимый пересчёт поля сюитой сверяется с движком,
// полотно держит корыто (максимум поля поперёк ширины), а не осевую отметку,
// перекрёсток — своя пластина с опорой, наложений со-плоскостных пластин 0,
// узлы стоят на своей опоре, бюджет мерится разогревом и лучшим из окон (12 тестов)
const rc = await import('/tests/relief-city.test.js');
await rc.runReliefCityTests();
```

Свежий зелёный прогон всех браузерных сюит — **243/243 по 15 сюитам**. Парсер
уровня (схема → нормализация → модуль главы, включая генератор кварталов и
разворот рельефа) тестируется отдельно на Node: `node tools/level-parser.test.mjs`
даёт **120/120**, арифметика поля — `node tools/relief.test.mjs` **11/11**.

Каждый модуль печатает отчёт `PASS/FAIL` и итог `N/M` в консоль, а также возвращает
объект `{ passed, total, results }`.

> Если после правок браузер отдаёт старую версию модулей из кэша, отключите кэш
> (DevTools → Network → «Disable cache») и перезагрузите страницу, либо запустите
> сервер на новом порту.

```
  architecture-map-contract.md  детали контракта карты: опциональные члены, реализации, общие механизмы
  architecture-glb.md           детали внешних ассетов (GLB): колонки, детерминизм, стриминг, ночной свет
  architecture-json-levels.md   детали уровней из брифа: пайплайн, окна/мусор/вывески, генератор,
                              русла, рельеф и косые кварталы (глава 12)
  architecture-terrain.md       детали рельефа: поверхности, пещеры, пропасти, мосты
  *-plan.md                     планы этапов (история)
  prompts/                      запросы и заметки владельца проекта
```

Глава 9 идёт пайплайном «бриф → Node → движок»: человек правит только
`level-09.json`, а `tools/` превращает его в нормализованные данные (плиты полов,
проступи маршей, пластины настилов, опоры и фонари), проверяет схему и пишет
модуль главы. `JsonMap` при этом не знает ни номера главы, ни схемы — он ест те
же данные, что и остальные типы карт едят свою `map`-секцию. Сборка уровня
(176 × 176 м, 4 дома в три этажа, 4 дороги двух ярусов): конструктор 41 мс,
`build` 11 мс, 148 AABB-солидов, 56 опорных плит, 6 аналитических призм
(4 наклонных пролёта настила и 2 откоса насыпи), 1235 узлов графа и 2153 ребра,
15 мешей уровня (2,6 тыс. треугольников),
5 источников света и 59 instanced-предметов окружения.

Новая глава — новый файл-определение в `src/levels/` + строка в `index.js`;
движок и карту править не нужно (уровень = данные, см. AGENTS.md).

**v1 и v2 генератора города.** Главы 9 и 10 — `kind: 'json'` (v1): только
ось-выровненные прямоугольники, и они заморожены — их брифы не правятся, а
побайтовая сверка модулей с парсером обязана проходить на каждом коммите v2.
v2 — тот же `JsonMap`, но с `kind: 'json2'`: класс не раздваивается, потому что
все общие механизмы (солиды, опоры, призмы, граф) уже там, а различие живёт в
данных. Поля v2 — `rotation` у здания, `elements`/`arc`/`connect` у дороги,
секция `relief` и `city.districts[].yaw`/`polygon` —
v1-схема отбраковывает явно, чтобы косой бриф не собрался молча
прямоугольником (проверки «v1 заморожен» в `tools/level-parser.test.mjs`).
Глава 11 — маленький район 200 м со всеми элементами v2: два косых дома (один —
вводимый: лобби, офис и склад под 30°, винтовой и прямой марши, люк на ходовую
кровлю с парапетом), две косые улицы, переход между домами, река с мостом и
бродом, развязка — дуга
R 40 м поднимается на 12 м и вливается в мост, — и съезд на землю.
План v2 и его замеры — `docs/city-v2-plan.md`.

**Глава 12 — рельефный мегаполис (v2 + `relief`).** 600 × 600 м с плавным
аналитическим полем: набережные и порт на нуле, деловой центр на террасе
+14,8 м, русло реки с тремя мостами, эстакада и развязка банкованными дугами,
четыре района генератора (три — под `yaw` −14°, 22° и −8°, один осевой; деловой
центр стоит на террасе), три иглы
верхнего яруса с переходом между кровлями и точкой B на них. Местность задаётся
не растром, а суммой холм-капсул (`height · ease(1 − d/radius)`) и площадок с
`blend`-кольцом; по этому же полю ходят нога, пуля, сфера, картинка грунта и
решётка навигации. Улицы кладёт парсер: `elements: [plate…]`, каждая пластина
держит **корыто** — максимум поля поперёк своей ширины (фит «по осевой» закапывал
поднятый борт проспекта на 0,24 м, а в кольце террасы — на 0,456 м), перекрёсток
— своя пластина с id, фонари повёрнуты на проезжую. Инвентарь собранной главы:
209 дорог (203 наземных, 5 мостов, 1 переход), 259 настилов (257 пластин и 2 дуги,
52 с подъёмом), 12 507 узлов графа, 440 фонарей, 70 опор, 81 дом (10 вводимых,
4 ходовые кровли), 521 предмет окружения, 6 капсул и 9 площадок рельефа; модуль
865 215 символов, предупреждений парсера 0; A→B — 228 узлов и 734 м пешком.
План главы, все замеры и открытые вопросы владельцу (бюджеты п. 6 превышены —
пороги не поднимались; фотометрия не дотягивает до «улица под фонарём 80») —
`docs/level12-relief-plan.md`, правила — раздел «Рельеф и косые кварталы» в
`docs/architecture-json-levels.md`.
