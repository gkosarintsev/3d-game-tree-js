# Автомобили уровня: правила

Дополнение к [AGENTS.md](../AGENTS.md), раздел «Автомобили уровня». Нормативные
правила здесь обязательны; замеры, выбранные точки и история — в
[docs/vehicle-plan.md](vehicle-plan.md).

## Данные и валидация

- Число машин и точки стоянок — **данные брифа**: `gameplay.cars: { count, spots: [{x, z, yaw}] }`.
  `CONFIG.car.count` по умолчанию 0; секция в модуль едет только у брифа с
  машинами (главы без неё не меняются).
- Нормализатор дописывает каждой точке `y` — отметку **её собственной опоры**
  (`support(x, z)`).
- Точки стоянок **авторские** (на трассах нет авто-якорей: наклонные настилы
  фонарей не носят, и раскладка света их пропускает).

Строгость (как у остальной схемы):
- **Ошибка (невыполнимое):** `count ≠ spots.length`, точка вне плиты мира, план
  корпуса в плане дома, два корпуса пересеклись.
- **Предупреждение (рискованное):** корпус за кромкой настила, точка в русле вне
  настила.
- **Молчит:** голый грунт (плита мира держит опору).

Геометрия проверок:
- Корпус мерится **планом** (длина × ширина с `yaw`, `obbHitsObb`), не центром.
- Кромка настила мерится **поперёк настила по его осям** (`deckSideMargin`: у
  дуги `halfW − |ρ − R|`, у повёрнутой пластины — локальная `v`); мировой
  габарит дуги для этого не годится.

## Поведение в движке

- Кузов — **декор**: не создаёт `solids`/`blockers`, пуля проходит сквозь (как
  зафиксированное свойство).
- Неуязвимость водителя — **право ведения**: `takeDamage` у `Player` и
  `AlienBody` ранит только при `vehicle === null`; `Weapon._tryFire` и
  `Alien._strike` в поездке молчат; viewmodel скрыт.
- Тело водителя в поездке — кузов: `position`, `direction`, `feetY` обеих ролей
  переопределены на машину; `update` делает ранний возврат (единая точка вместо
  правок всех потребителей).
- Выход: сбоку от кузова с **отметкой пола кузова** и зазором по **телу
  водителя** (`cfg.radius` роли). `spawnAt` ищет опору не выше переданной точки.
- Камера — **жёсткое преследование** (мышь не трогает), с подъёмом над
  **собственной** опорой (`camera.minClearance`).
- Поступь — велосипедная модель: `yaw += v / база · tan δ · dt`, `δ` остывает
  (`steerFade`), разворота на месте нет. Кузов клампится по `map.bounds`/плите
  по принятым правилам тела; съезд с кромки — падение по вертикальной скорости
  до опоры, не телепорт.
- Клавиша `F` — фронт-детект в `Game._rideToggle` (не в теле/машине), чтобы
  удержание не давало цикл сесть/выйти.

## Проверки

8 проверок данных в `tools/level-parser.test.mjs` и 13 сценариев в
`tests/vehicle.test.js` (данные, опора, отсутствие коллизий, посадка/выход,
неуязвимость ролей, поездка, управление/накат, камера, падение, перила, радиус
водителя, `shiftWorld`/`dispose`, детерминизм).
