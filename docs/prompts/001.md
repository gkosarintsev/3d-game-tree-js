\### 1. Особенности Чужого (Alien / Xenomorph)



Чужой — самый сложный персонаж с точки зрения физики и навигации, так как он игнорирует стандартную «гравитационную» сетку уровня.



\* \*\*Трехмерная навигация и ходьба по поверхностям (Wall-Walking / Free Wall-Climbing):\*\*

\* \*Физический движок:\* Обычные 3D-движки рассчитывают ориентацию персонажа относительно глобального вектора гравитации (ось $Z$ или $Y$). Для Чужого вектор «низа» (Up-vector) должен динамически пересчитываться под нормаль поверхности (потолок, стены, трубы), по которой он перемещается (через рейкасты/Raycasting).

\* \*Камера:\* Камера должна плавно планарно вращаться вслед за изменением ориентации тела, чтобы игрока не укачивало, сохраняя при этом сцепление с геометрией уровня.





\* \*\*ИИ и поиска пути (Pathfinding / NavMesh):\*\*

\* Стандартный NavMesh (2D-сетка на полу) для ИИ-Чужих не подходит. Движок должен поддерживать \*\*3D NavMesh\*\* или графы узлов (Node Graphs), проложенные по потолкам, вентиляциям и стенам, чтобы NPC-Чужие могли обходить игрока со всех плоскостей.





\* \*\*Высокая скорость и анимирование (Animation Blending):\*\*

\* Движок должен справляться с быстрой сменой состояний движения (бег по полу $\\rightarrow$ прыжок на стену $\\rightarrow$ карабканье по потолку). Для этого используется сложная инверсная кинематика (IK) для лап, чтобы они корректно прилипали к неровностям геометрии на высокой скорости.





\* \*\*Кислотная кровь (Acid Blood / Particulate Effects):\*\*

\* При получении урона хитбоксы Чужого должны спавнить динамические частицы кислоты, которые разъедают геометрию/наносят урон объектам в месте попадания (требуются события пересечения частиц с мешами уровня).
